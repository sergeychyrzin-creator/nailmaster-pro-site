# NailMaster Pro — сайт для GitHub Pages

Загрузите `index.html` и папку `assets` в корень репозитория GitHub Pages. Кнопка скачивания ведёт на предоставленную ссылку Яндекс Диска. Кнопки Telegram/оплаты ведут на https://t.me/NailMaster_Pro.

В `assets` находятся главное фото и изображения тарифов FREE, Premium и VIP.
